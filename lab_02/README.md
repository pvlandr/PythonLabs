# Лабораторная работа 2. Потоковый анализатор файлов

Python-пакет `streamstats`, читающий события из CSV и JSONL и создающий отчёт в формате JSON.

## Функциональность
 * Поддерживает форматы CSV и JSONL
 * Валидирует обязательные поля (`timestamp`, `level`, `source`, `message`)
 * Создает отчет, который содержит:
    * Общее число событий
    * Количество событий каждого уровня
    * Количество событий каждого источника
    * Top-5 источников событий уровня ERROR/CRITICAL. Если несколько источников имеют одинаковое количество таких событий, то первом в списке будет источник, первое событие которого появилось раньше всего в анализируемых файлах.
    * Первую и последнюю временную метку
 * Объединяет статистику нескольких файлов одного формата.

## Команды
 * `python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json`
    * Анализирует файлы, указанные как `INPUT` формата, указанного в `--format` и записывает отчет в файл, указанный в `--output`
 * `python -m streamstats analyze INPUT [INPUT ...] --format csv|jsonl --output REPORT.json --skip-invalid`
    * Пропускает неверные строки, выводит их как предупреждения в лог и записывает количество пропущенных строк в отчет.
