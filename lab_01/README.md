# Лабораторная работа 1. Консольный набор утилит
Python-пакет, содержащий калькулятор и конвертер величин. Поддерживает CLI.

## Калькулятор
 * Поддерживает целые и вещественные числа.
 * Поддерживает бинарные операторы `+`, `-`, `*` и `/`.
 * Поддерживает унарные операторы `+` и `-` перед числами.
 * Поддерживает скобки.
 * Игнорирует пробелы между числами, операторами и скобками.
 * Соблюдает приоритет бинарных операторов.
 * Возвращает результат как `Decimal`, округленный до 10-го знака после точки.

## Конвертер величин
 * Поддерживает единицы:
   * температуры: `c`, `f`, `k`
   * массы: `g`, `kg`
   * длины: `mm`, `cm`, `m`, `km`
 * Не учитывает регистр единиц
 * Запрещает температуру меньше абсолютного нуля (-273 c), а также отрицательную массу и длину.
 * Возвращает результат как `Decimal`, округленный до 10-го знака после точки.

## Команды
 * `python -m toolkit calc "EXPRESSION"`
   * Вычисляет выражение `EXPRESSION`.
   * Пример: `python -m toolkit calc "2 + 2"` (результат: `4`)
 * `python -m toolkit convert VALUE --from UNIT1 --to UNIT2`
   * Переводит значение `VALUE` из единицы `UNIT1` в единицу `UNIT2`
   * Пример: `python -m toolkit convert 0 --from K --to C` (результат: `-273`)
 * `python -m toolkit --help`
   * Выводит информацию о командах пакета
